APP STORE REVIEW NOTES — Kindred Photos

Thank you for reviewing Kindred Photos.

== DEMO ACCESS ==

Tap "Try the demo" on the login screen to explore the app with sample data. No account or server setup is required. This provides full access to browse the interface, including:
- Home feed with photo scatter and people carousel
- Library with People, Pets, and Vehicles tabs
- Search functionality
- Photo detail viewer
- Settings and notifications

== WHAT THIS APP DOES ==

Kindred Photos is a household photo management app. Families back up their photos to Flickr, and Kindred organizes them using AI — grouping photos by person, pet, location, and moment. It runs on the user's own self-hosted server, so photos never leave the family's control.

== REQUIRES A SELF-HOSTED BACKEND ==

For full functionality (beyond demo mode), the app connects to a self-hosted backend server running our open-source FastAPI service. This is by design — Kindred is a privacy-first product where all photo processing happens on infrastructure the user owns.

The demo mode demonstrates the complete UI without requiring a backend.

== FLICKR INTEGRATION ==

The app integrates with Flickr for photo storage. Users who connect a Flickr account (via OAuth) can upload and browse their photo library. The Flickr login flow uses ASWebAuthenticationSession for the OAuth handshake.

== PHOTO LIBRARY ACCESS ==

The app requests photo library access for the backup feature, which allows users to upload photos from their device to their Flickr storage through the Kindred backend. This is an opt-in feature accessible from Settings > Backup.

== BACKGROUND PROCESSING ==

The app registers for background fetch and processing tasks to sync photo metadata and check for new photos. This is configured in Info.plist under UIBackgroundModes (fetch, processing) and BGTaskSchedulerPermittedIdentifiers.

== PRIVACY ==

- All photo processing (face recognition, object detection) runs on the user's self-hosted server, not in the cloud
- The app communicates only with the user's designated backend server and Flickr
- No photo data is sent to any third party
- Anonymous analytics via PostHog (optional, can be disabled)
- Full privacy policy: https://kindredphotos.app/privacy
