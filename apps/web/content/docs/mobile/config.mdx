description: Connect the Kindred Photos iOS app to your household.

## Pair your iPhone

1. Sign in to Kindred on the web. Open your account menu and select **Mobile setup**. You can also go to **Settings → Household → Pair a device**.
2. Select **Create a pairing code**.
3. Open Kindred on your iPhone. On the sign-in screen, tap **Scan a pairing code** and point the camera at the code on your computer.
4. The web page confirms when your device is paired.

The code expires after 10 minutes and can be used once. Keep it private, since it signs the next device that claims it in to your Kindred account.

## Enter the code manually

On the scan screen, tap **Enter the code instead**. If the app asks for your server address, use the address shown beside the pairing code. Enter the code as displayed on the web.

## Troubleshooting

- **Code expired** — Create a new pairing code on the web and scan it again.
- **Camera access is off** — Enter the code manually, or allow camera access for Kindred in iPhone Settings.
- **Can’t reach the server** — Check that your iPhone can reach the server address. For a private home server, connect to your home network or VPN first.
