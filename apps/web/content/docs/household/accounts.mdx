## Overview

Kindred Photos supports household accounts so family members can browse the photo library without needing their own Flickr account. The admin (who connected Flickr) has full control, while members can browse, search, and upload photos.

## Roles

| Role | Capabilities |
|------|-------------|
| **Admin** | Connect Flickr, run scans, label/merge/dismiss clusters, delete photos, manage members, create invites, intelligence settings |
| **Member** | Browse all photos, search, view clusters, timeline, locations, events, upload photos |

Admins can promote members to admin or demote admins to members from the Settings page. See [Roles](/docs/household/roles) for the full comparison.

## Inviting members

You can invite family members by email (using the Resend integration) or by sharing a manual invite code. See [Invites](/docs/household/invites) for the full setup guide.

The quick version:

1. Go to **Settings** (gear icon in the user menu)
2. Click **Invite member** (email) or **Create invite code** (manual)
3. Share the invite code or link with a family member

Invite codes are 8 characters, expire after 7 days, and can only be used once.

## Member registration

Members can register at `/join` or use the direct invite link:

```
https://your-kindred.com/join?code=ABC12345
```

They'll create a username, display name, and password. No Flickr account needed.

## Avatars

Every household member can set a profile avatar. Kindred Photos lets you pick a photo from your own library and crop it to use as your profile picture.

To set your avatar:

1. Click your avatar (or initials) in the top navigation
2. Select **Edit profile**
3. Choose a photo from the library or upload a new one
4. Crop and save

Avatars appear throughout the app -- in the navigation bar, notification messages, and household member lists.

## Managing members

From the Settings page, admins can:

- View all household members and their roles
- Promote a member to admin or demote an admin to member
- Remove members (immediately revokes access)
- View and revoke active invite codes

## Photo uploads

Photo uploads go to the Flickr account configured in the backend's `.env` file (`FLICKR_OAUTH_TOKEN` and `FLICKR_USER_ID`). This is typically the admin's Flickr account. All household members browse the same library from this account.

If your household has multiple Flickr accounts (e.g. one per family member), the admin can change which account is configured in the backend environment. Support for multiple linked Flickr accounts per household is planned for a future release.

## How it works

- Members authenticate with username/password
- Sessions are stored in the database and expire after 30 days
- The admin authenticates via Flickr OAuth (same as before)
- All data is shared — members see the same photos, clusters, and labels
- Destructive actions (scan, delete, label, merge) are admin-only at the API level
