## System overview

The web and iOS apps send requests to the household's Kindred API. PostgreSQL
with pgvector holds accounts, permissions, and the catalog. The NAS keeps
originals and runs the indexers. Flickr can mirror supported uploads, and
Cloudflare R2 can serve generated thumbnails when configured.

The web, API, database, and original storage can all run on one NAS. Each
installation configures its own addresses and storage credentials.

## Backend

The backend is a single Python FastAPI service that handles:

- **Photo scanning** — Reads media from the installation’s configured sources and runs detection models
- **Face detection** — InsightFace (ArcFace) at 960px resolution
- **Pet/vehicle detection** — YOLOv8
- **Embedding generation** — CLIP ViT-B-32 for text/image search
- **Clustering** -- DBSCAN + agglomerative clustering for face grouping
- **Upload proxy** -- Saves uploads to NAS storage and queues a Flickr copy if configured
- **Notifications** -- Push (APNs) and in-app notifications for scan events and new discoveries
- **API** -- RESTful endpoints for the web and mobile clients

All models run on CPU. No GPU required.

## Database

PostgreSQL with the pgvector extension stores:

- **Detections** — Face/pet/vehicle bounding boxes, confidence scores, base64 chips
- **Embeddings** — 512-dimensional vectors for face recognition and CLIP search
- **Clusters** — Groupings of detections into people/animals
- **Metadata** — Photo dates, locations, text (OCR), colors

## Web frontend

Next.js app that proxies all API requests through a server-side route (`/api/backend/`). This keeps the API key server-side and allows deployment on Vercel without CORS issues.

## iOS app

The iOS app stores a signed-in session for the server you paired with. In a
default NAS installation, the app talks directly to that installation's API
over HTTPS.

## Photo storage

NAS originals, provider copies, and catalog data have separate lifecycles.
Deleting a household in Kindred removes its accounts and catalog. The server
operator manages the files held on the NAS, in R2, and in Flickr.
