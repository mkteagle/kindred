## Docker Compose

The backend ships with a `docker-compose.yml` that runs two services:

- **backend** — FastAPI app with face detection models
- **caddy** — Reverse proxy with automatic HTTPS

```yaml
services:
  backend:
    build: .
    restart: unless-stopped
    volumes:
      - ./data:/app/data
      - ./main.py:/app/main.py
    env_file: .env
    environment:
      - PYTHONUNBUFFERED=1
    expose:
      - "8000"

  caddy:
    image: caddy:alpine
    restart: unless-stopped
    ports:
      - "80:80"
      - "443:443"
    volumes:
      - ./Caddyfile:/etc/caddy/Caddyfile:ro
      - caddy_data:/data
      - caddy_config:/config
    depends_on:
      - backend

volumes:
  caddy_data:
  caddy_config:
```

## Caddyfile

Create a `Caddyfile` in the backend directory:

```
your-domain.com {
    reverse_proxy backend:8000
}
```

Caddy automatically provisions and renews SSL certificates from Let's Encrypt — no manual configuration needed.

## Commands

```bash
# Start
docker compose up -d

# View logs
docker compose logs -f backend

# Restart after code changes
docker compose restart backend

# Rebuild after dependency changes
docker compose up -d --build
```

## Updating

The `main.py` file is volume-mounted, so you can update the backend code without rebuilding:

```bash
# Pull latest code
git pull

# Restart to pick up changes
docker compose restart backend
```

If `requirements.txt` changes, rebuild the image:

```bash
docker compose up -d --build
```

## Database

Kindred Photos uses PostgreSQL with the pgvector extension. You can use any PostgreSQL provider:

- [Railway](https://railway.app) — managed PostgreSQL with pgvector
- [Neon](https://neon.tech) — serverless PostgreSQL with pgvector
- Self-hosted PostgreSQL with `CREATE EXTENSION vector`

Set the connection string in `backend/.env`:

```bash
DATABASE_URL=postgresql://user:password@host:5432/kindred
```
