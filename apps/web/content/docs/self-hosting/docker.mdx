---
title: Docker deployment
description: Run the Kindred API, web app, and database with Docker Compose.
---

The [NAS setup](/docs/self-hosting/nas) uses the Compose project in `deploy/ugreen` and also applies to Docker-capable Linux hosts. It packages the API, web app, PostgreSQL with pgvector, and an optional Cloudflare Tunnel.

From `deploy/ugreen`, use `docker compose ps` to see service status and `docker compose logs -f api` to inspect API logs. Persist the original media and database directories and back them up before updating.
