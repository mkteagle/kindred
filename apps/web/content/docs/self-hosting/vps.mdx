## Recommended providers

Any Linux VPS with 4GB+ RAM works. Affordable options:

| Provider | Plan | RAM | Cost |
|----------|------|-----|------|
| Hetzner | CPX11 | 2GB | ~$4/mo |
| Hetzner | CPX21 | 4GB | ~$7/mo |
| DigitalOcean | Basic | 4GB | $24/mo |
| Oracle Cloud | Ampere A1 | 4GB | Free tier |

## Initial server setup

```bash
# SSH into your VPS
ssh root@your-server-ip

# Install Docker
curl -fsSL https://get.docker.com | sh

# Install Docker Compose plugin
apt install docker-compose-plugin

# Clone the repo
git clone https://github.com/mkteagle/kindred.git
cd kindred/backend

# Configure
cp .env.example .env
nano .env  # Add your credentials
```

## HTTPS

The included `docker-compose.yml` uses **Caddy** as the reverse proxy, which automatically provisions and renews SSL certificates from Let's Encrypt.

Create a `Caddyfile` in the backend directory with your domain:

```
your-domain.com {
    reverse_proxy backend:8000
}
```

That's it — Caddy handles everything else. No manual certificate management needed.

## Firewall

```bash
ufw allow 22    # SSH
ufw allow 80    # HTTP
ufw allow 443   # HTTPS
ufw enable
```

## Updating

```bash
cd /root/kindred/backend
git pull
docker compose restart backend
```
