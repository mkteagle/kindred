---
title: Installation
description: Install Kindred on your own NAS or server.
---

Start with [NAS setup](/docs/self-hosting/nas). The bundled Docker Compose project runs the API, web app, and PostgreSQL together on a Docker-capable NAS or Linux computer.

1. Initialize the NAS project and create your owner account.
2. Sign in on your own web address and [pair the iPhone app](/docs/mobile/config).
3. Upload to your NAS or import an existing library. Connect [Flickr](/docs/getting-started/flickr-setup) if you want a second copy of supported uploads.

For an optional hosted web frontend, see [Vercel deployment](/docs/self-hosting/vercel).
