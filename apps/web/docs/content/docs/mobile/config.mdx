## Setup

Set `PUBLIC_API_URL` and `PUBLIC_WEB_URL` to your installation’s HTTPS addresses. Sign in to Kindred on the web and open **Mobile setup**. On the iPhone, choose **Scan a pairing code** and confirm the server address to sign in.

You can also choose **Enter server address** and sign in with a household account or join with an invitation. The household owner connects Flickr from the web integration settings.

## Config endpoint

The public `/app-config` endpoint reports the server’s capabilities:

```bash
curl https://api.your-domain.com/app-config
```

```json
{
  "api_version": "1.0",
  "app_name": "Kindred",
  "features": {
    "flickr_integration": true,
    "face_detection": true,
    "pet_detection": true,
    "vehicle_detection": true
  },
  "auth": {
    "method": "session",
    "header": "X-Session-Token"
  }
}
```

This endpoint requires no authentication.

## Authentication

The server issues each signed-in device a session tied to its household account. The iOS app stores that session in the device Keychain. Keep Flickr credentials and the web-to-API key on the server.

## Troubleshooting

- **Connection failed** — Verify your backend URL is accessible from the internet. Check firewall rules.
- **401 Unauthorized** — Sign in again or create a new pairing code on your household’s server.
- **SSL errors** — Ensure your backend has a valid HTTPS certificate (use Caddy for automatic HTTPS).
