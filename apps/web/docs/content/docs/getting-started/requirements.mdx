---
title: Requirements
description: What you need to run Kindred Photos on a NAS or home server.
---

- A Docker-capable NAS or always-on Linux computer that can run the Kindred images.
- Docker Compose and PostgreSQL with pgvector. The NAS setup includes PostgreSQL in its Compose project.
- Free storage for your originals, PostgreSQL data, generated thumbnails, and model files. Image recognition benefits from additional CPU and RAM.
- HTTPS addresses for Kindred's web and API services. An iPhone must be able to reach its paired API through the home network, VPN, or public HTTPS.

Flickr, Vercel, and hosted PostgreSQL are optional services. [Start with NAS setup](/docs/self-hosting/nas).
